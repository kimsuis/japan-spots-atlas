# 일본 관광지 지도

일본 47개 도도부현의 관광지 1,617곳을 지도와 카드로 정리한 페이지예요.
**https://kimsuis.github.io/japan-spots-atlas/**

- 대중교통 기준 가는 법, 가까운 역, 해당되는 JR 지역 패스(외국인용)
- 추천 계절·축제 날짜, 필요한 시간, 대략적인 비용, 걷는 양
- 지방·종류·계절·추천도·패스로 거르기, 검색

조사 기준일은 2026-10-27이에요. 운행 시각, 요금, 축제 날짜, 패스 적용 범위는 바뀔 수 있으니 출발 전에 공식 사이트에서 확인하세요.
